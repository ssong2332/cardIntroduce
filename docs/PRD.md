# PRD — 카드 인트로듀스 (cardIntroduce)

> 소유자: planner | 상태: 승인 | 최종 수정: 2026-09-07
> (vibe 모드로 진행 중 — 메인 세션 직접 관리)

## 한 줄 정의

세미 라운드 카지노 포커 테이블에서 딜러가 카드를 섞고 뒤집어 멋쟁이사자처럼(LikeLion) 카드 뒷면에서 사람 프로필 앞면으로 공개하며, 공개 순간 화면 중앙에 대형 스포트라이트로 강조한 뒤 3개 팀 좌석에 안착시키는 100vh 프리미엄 팀 빌딩 웹 애플리케이션.

## 배경 / 문제

vibe 모드 — 생략

## 사용자

vibe 모드 — 생략

## 요구사항

### 기능 요구사항

| ID | 요구사항 | 우선순위 (필수/권장/보류) | 승인 기준 (검증 가능한 조건 — Given-When-Then 권장) |
|---|---|---|---|
| F-01 | 세미 라운드 포커 테이블 레이아웃 | 필수 | Given 앱 실행 시, When 화면에 렌더링되면, Then 딥 펠트 테이블 상단에 딜러 스테이션이 있고 하단 원호(아크)를 따라 3개 팀 좌석이 배치된 세미 라운드 포커 테이블이 100vh 스크롤 없이 표시된다. |
| F-02 | 멋쟁이사자처럼(LikeLion) 카드 뒷면 디자인 | 필수 | Given 카드가 뒷면 상태일 때, When 보여지면, Then 멋쟁이사자처럼의 시그니처 오렌지 컬러와 사자(Lion) 엠블럼, 정교한 포커 카드 백 기하학 패턴이 표시된다. |
| F-03 | 카드 앞면 인물 프로필 디자인 | 필수 | Given 카드가 앞면으로 뒤집히면, When 보여질 때, Then 사람 이름, 포지션/역할, 아바타 사진, 멋쟁이사자처럼 기수/트랙, 한줄 모토가 선명하게 표시된다. |
| F-04 | 딜러의 카드 공개 & 중앙 대형 스포트라이트 하이라이트 | 필수 | Given 딜러가 카드를 드로우하여 뒤집을 때, When 플립되면, Then 즉시 해당 카드가 화면 중앙에서 큼직하게 확대(Highlight Hero Card)되어 인물 정보가 뚜렷하게 보이고, 이후 해당 팀 좌석으로 슬라이딩 안착한다. |
| F-05 | 3팀 시나리오 파이프라인 | 필수 | Given 단계별 진행 시, When 딜러가 진행하면, Then 1트랙 안내 → 3팀 팀장(1명, 1명, 2명) 딜러 오픈 → 팀장 우선선발(각 2명) 딜러 오픈 → 남은 인원 덱 셔플 & 순차 딜링 배정 순으로 진행된다. |
| F-06 | 팀별 대형 포커스 쇼케이스 | 필수 | Given 전원 안착 후, When '팀별 크게 보기'를 선택하면, Then 1팀씩 포커 테이블 중앙에 팀장 및 팀원 전체 카드가 대형 카드로 정렬되어 이전/다음 팀으로 넘겨볼 수 있다. |
| F-07 | 시드 기반 결정론적 추첨 | 필수 | Given 특정 시드가 주어지면, When 딜러가 카드를 셔플하고 나누면, Then 항상 약속된 순서와 팀으로 배정된다. |
